Friend, the wall does not matter **as long as the furnace is on the same data network** as your display logic. The Advanced Furnace exposes data/power connections and readable values like `Pressure`, `Temperature`, `Reagents`, gas ratios, `TotalMoles`, import/export counts, etc. [Stationeers Wiki+1](https://stationeers-wiki.com/Advanced_Furnace)

### Simple hardwired way

For each number you want to show:

1.  Run **data cable** from the Advanced Furnace’s data port through/around the wall to your control room.

2.  Place an **LED Display**.

3.  Place a **Logic Reader**.

4.  Set the Logic Reader:

    -   **Input device:** Advanced Furnace

    -   **Variable:** e.g. `Pressure`, `Temperature`, `Reagents`, `TotalMoles`, `RatioOxygen`, etc.

5.  Place a **Logic Writer**.

6.  Set the Logic Writer:

    -   **Input:** Logic Reader

    -   **Output:** LED Display

    -   **Output variable:** `Setting`


LED displays show whatever number is written into their `Setting` variable. Their `Mode` controls formatting, such as normal number, percent, Kelvin, mol, or Pascal. Useful modes: `1 = percent`, `3 = Kelvin`, `13 = mol`, `14 = Pa`. [Stationeers Wiki](https://stationeers-wiki.com/Console?utm_source=chatgpt.com)

So for furnace pressure:

```
```
Advanced Furnace Pressure -> Logic Reader -> Logic Writer -> LED Setting
LED Mode = 14
```
```

For furnace temperature:

```
```
Advanced Furnace Temperature -> Logic Reader -> Logic Writer -> LED Setting
LED Mode = 3
```
```

For gas ratios:

```
```
Advanced Furnace RatioOxygen -> Logic Reader -> Logic Writer -> LED Setting
LED Mode = 1
```
```

The furnace gas ratio fields are already `0.0` to `1.0`, so percent mode works directly. [Stationeers Wiki](https://stationeers-wiki.com/Advanced_Furnace)

### Better way: one IC10 chip driving several LEDs

Use this if you want a clean panel with pressure, temperature, reagents, and gas ratios.

Set device screws like this:

```
```
d0 = Advanced Furnace
d1 = Pressure LED
d2 = Temperature LED
d3 = Reagents LED
d4 = O2 Ratio LED
d5 = Volatiles Ratio LED
```
```

IC10 code:

```
asm

```
alias AdvancedFurnace d0
alias PressureDisplay d1
alias TemperatureDisplay d2
alias ReagentsDisplay d3
alias OxygenRatioDisplay d4
alias VolatilesRatioDisplay d5

alias FurnacePressure r0
alias FurnaceTemperature r1
alias FurnaceReagents r2
alias FurnaceOxygenRatio r3
alias FurnaceVolatilesRatio r4

start:
    l FurnacePressure AdvancedFurnace Pressure
    l FurnaceTemperature AdvancedFurnace Temperature
    l FurnaceReagents AdvancedFurnace Reagents
    l FurnaceOxygenRatio AdvancedFurnace RatioOxygen
    l FurnaceVolatilesRatio AdvancedFurnace RatioVolatiles

    s PressureDisplay Setting FurnacePressure
    s PressureDisplay Mode 14

    s TemperatureDisplay Setting FurnaceTemperature
    s TemperatureDisplay Mode 3

    s ReagentsDisplay Setting FurnaceReagents
    s ReagentsDisplay Mode 0

    s OxygenRatioDisplay Setting FurnaceOxygenRatio
    s OxygenRatioDisplay Mode 1

    s VolatilesRatioDisplay Setting FurnaceVolatilesRatio
    s VolatilesRatioDisplay Mode 1

    yield
    j start
```
```

IC10 device registers `d0` through `d5` are selected with the housing screws, and `l` reads a logic field while `s` writes one. [Stationeers Wiki+1](https://stationeers-wiki.com/IC10)

### If you cannot run cable through the wall

Use **Logic Transmitters**. Put one transmitter near the furnace side, set it active, write a value into its `Setting`, then read that `Setting` from a passive transmitter in the control room. Logic Transmitters wirelessly transmit values, and passive transmitters can read the active transmitter’s `Setting`. [Stationeers Wiki](https://stationeers-wiki.com/Logic_Transmitter)

Caveat: a transmitter pair is basically one value channel unless you start encoding multiple values yourself, so for pressure + temperature + ratios, plain data cable or IC10 is cleaner.
